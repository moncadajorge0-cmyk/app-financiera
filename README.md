# 💰 Financial Organization Manager

A web-based financial management application designed to help users organize their personal finances efficiently. The application allows users to register loans, income, expenses, and other financial transactions, while generating detailed PDF reports for easy tracking and financial analysis.

---

## 📋 Overview

Managing personal finances can be challenging when dealing with multiple loans, expenses, and sources of income. Financial Organization Manager provides a simple and intuitive solution to keep all financial information in one place.

Users can record their financial activities, monitor their cash flow, and generate professional PDF reports that summarize their financial situation.

---

## ✨ Features

* 📌 Register and manage loans and credits
* 💵 Record income sources
* 💸 Track expenses and payments
* 📊 Monitor cash inflows and outflows
* 📄 Generate downloadable PDF reports
* 📈 View financial summaries
* 💾 Store financial data locally
* 📱 Responsive and user-friendly interface

---

## 🚀 Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* jsPDF (PDF generation)
* Local Storage

## 📦 Installation

### Clone the repository

```bash
git clone https://github.com/your-username/financial-organization-manager.git
```

### Navigate to the project folder

```bash
cd financial-organization-manager
```

### Run the application

Simply open the `index.html` file in your browser.

Alternatively, you can use a local development server:

```bash
npx serve
```

or

```bash
python -m http.server 8000
```

Then open:

```
http://localhost:8000
```
